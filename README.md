\# Sales Dashboard



A Python-based sales analysis dashboard using pandas, numpy, and matplotlib.



\## Features

\- 📊 Sales trend analysis

\- 🏆 Top performing products

\- 🌍 Regional sales breakdown

\- 📈 Category-wise analysis

\- 💰 Revenue metrics



\## Installation



```bash

python -m venv venv

venv\\Scripts\\activate

pip install -r requirements.txt

```



\## Usage



```bash

cd scripts

python generate\_data.py

python sales\_dashboard.py

```



\## Results

\- 2500+ sales records

\- 6-chart dashboard visualization

\- Revenue metrics and KPIs
